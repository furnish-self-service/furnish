Furnish 0.1.0 is the first stable release of the self-service app catalog for Windows, macOS and Linux. Administrators publish collections in Git. People can install individual apps or kits, preview changes, and see the results in Activity.

- Windows x64 users can install the MSI. On Apple silicon, use the DMG or the Furnish Homebrew cask.
- Linux users can install from the signed stable APT or RPM repository. The standalone Linux x86-64 CLI is also included.
- Desktop self-updates verify the project's signature and the version it covers. Linux package managers verify signed repository metadata. The Windows installer has no publisher certificate, and the macOS app uses ad-hoc signing without Apple notarization. First launch can require OS approval. Managed-device policy may require your administrator to deploy Furnish.
